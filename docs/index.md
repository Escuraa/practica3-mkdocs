# Pràctica 3 · MkDocs i Material

Lloc de documentació creat amb MkDocs i el tema Material per a la pràctica 3 d'IAW (2ASIX).

## Què és MkDocs

MkDocs és un generador de llocs estàtics pensat per a documentació. Els continguts s'escriuen en Markdown i la configuració es guarda en `mkdocs.yml´.

## Publicació

El lloc es genera amb `mkdocs build` i es publica a GitHub Pages amb `mkdocs gh-deploy´.

Més informació: [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)
